Minimal anonymous voting website:

1. Open `/home/runner/work/skills-copilot-codespaces-vscode/skills-copilot-codespaces-vscode/index.html` in a browser.
2. Five people submit one vote each (name of the person they find most attractive).
3. After the fifth vote, the answers are revealed in shuffled order.
